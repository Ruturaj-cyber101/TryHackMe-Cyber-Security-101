# Moniker Link

## Room Overview
This room explains the Moniker Link vulnerability, a Windows shortcut (.LNK) exploitation technique that allows code execution when a malicious shortcut is processed.

---

## Key Concepts Learned

- What Moniker Link (.LNK) files are
- How malicious shortcut files can be abused
- Understanding exploitation through user interaction
- Why Windows shortcut handling can be dangerous

---

## Practical Skills Gained

- Identified how LNK-based exploits work
- Understood attack flow from delivery to execution
- Recognized risks related to file-based exploitation
- Improved awareness of Windows exploitation techniques

---

## SOC Relevance

Moniker Link exploitation knowledge helps SOC analysts to:
- Detect malicious shortcut files
- Investigate phishing and malware delivery methods
- Understand Windows-based exploitation techniques
