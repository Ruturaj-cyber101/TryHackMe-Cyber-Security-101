# TCPDUMP: The Basics

## Room Overview
This room introduces tcpdump, a command-line network packet capture tool commonly used for traffic analysis and troubleshooting.

---

## Key Concepts Learned

- What tcpdump is and where it is used
- Capturing live network traffic from interfaces
- Understanding packet output and headers
- Using basic tcpdump filters
- Saving packet captures for later analysis

---

## Practical Skills Gained

- Captured network traffic using tcpdump
- Identified source and destination IP addresses
- Analyzed protocol information from packet output
- Applied basic filtering to focus on relevant traffic
- Used command-line tools for traffic inspection

---

## SOC Relevance

tcpdump is useful for SOC analysts to:
- Quickly inspect live network traffic
- Capture evidence during investigations
- Support incident response and network troubleshooting
