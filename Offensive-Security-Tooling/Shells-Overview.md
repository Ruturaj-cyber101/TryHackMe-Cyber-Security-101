# Shells Overview

## Room Overview
This room explains what shells are and how attackers use them to interact with compromised systems after gaining access.

---

## Key Concepts Learned

- What a shell is
- Difference between reverse shell and bind shell
- Interactive vs non-interactive shells
- Why shells are important after exploitation

---

## Practical Skills Gained

- Understood how shells provide system access
- Learned common shell types used by attackers
- Recognized how shells are established
- Built foundation for post-exploitation concepts

---

## SOC Relevance

Shells knowledge helps SOC analysts to:
- Detect suspicious outbound connections
- Identify post-exploitation activity
- Investigate compromised hosts
- Understand attacker persistence techniques
