# SQLMap: The Basics

## Room Overview
This room introduces SQLMap, an automated tool used to detect and exploit SQL injection vulnerabilities in web applications.

---

## Key Concepts Learned

- What SQLMap is and how it works
- Automated detection of SQL injection
- Database enumeration basics
- Risks of insecure input validation

---

## Practical Skills Gained

- Used SQLMap to test vulnerable parameters
- Identified SQL injection flaws
- Extracted basic database information
- Understood automation in web exploitation

---

## SOC Relevance

SQLMap knowledge helps SOC analysts to:
- Recognize SQL injection attack patterns
- Analyze malicious web requests
- Improve detection of automated exploitation tools
- Support web application incident response
