# Gobuster: The Basics

## Room Overview
This room introduces Gobuster, a tool used for brute-forcing directories, files, and DNS subdomains on web servers.

---

## Key Concepts Learned

- What Gobuster is and its use cases
- Directory and file enumeration
- DNS and virtual host enumeration
- Importance of hidden resources in web security

---

## Practical Skills Gained

- Ran directory brute-force scans
- Identified hidden files and directories
- Used wordlists effectively
- Interpreted enumeration results

---

## SOC Relevance

Gobuster knowledge helps SOC analysts to:
- Detect reconnaissance activity
- Identify suspicious scanning behavior
- Improve web server monitoring and alerting
