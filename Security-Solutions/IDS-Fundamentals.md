# IDS Fundamentals

## Room Overview
This room introduces Intrusion Detection Systems (IDS) and explains how they are used to detect suspicious or malicious activity in networks and systems.

---

## Key Concepts Learned

- What an IDS is
- Difference between IDS and IPS
- Network-based and host-based IDS
- Signature-based vs anomaly-based detection

---

## Practical Skills Gained

- Understanding how IDS detects threats
- Awareness of alert generation
- Knowledge of detection methods
- Foundation for monitoring suspicious activity

---

## SOC Relevance

IDS tools are important for SOC analysts as they:
- Detect potential intrusions
- Generate alerts for investigation
- Support threat detection strategies
- Improve network visibility
