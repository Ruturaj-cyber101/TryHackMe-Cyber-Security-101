# Web Application Basics

## Room Overview
This room introduces the fundamentals of web applications and how users interact with web servers through browsers and HTTP requests.

---

## Key Concepts Learned

- What web applications are
- Client-server architecture
- Frontend vs backend
- Role of HTTP and HTTPS
- Common web technologies

---

## Practical Skills Gained

- Understood how web applications function
- Identified basic web components
- Learned how browsers communicate with servers
- Built foundational knowledge for web security

---

## SOC Relevance

Web application basics help SOC analysts to:
- Understand normal vs abnormal web traffic
- Analyze web-based attacks
- Support investigations involving web applications
