# Burp Suite: The Basics

## Room Overview
This room introduces Burp Suite, a popular web application testing tool used to intercept, inspect, and modify HTTP requests and responses.

---

## Key Concepts Learned

- What Burp Suite is and how it works
- Understanding HTTP requests and responses
- Intercepting and modifying traffic
- Burp Suite Proxy and Repeater basics

---

## Practical Skills Gained

- Configured browser to work with Burp Suite
- Intercepted web traffic
- Modified HTTP requests
- Analyzed web application behavior

---

## SOC Relevance

Burp Suite knowledge helps SOC analysts to:
- Understand how web attacks are performed
- Analyze suspicious HTTP traffic
- Support web application security investigations
