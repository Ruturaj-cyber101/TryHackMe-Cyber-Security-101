# SQL Fundamentals

## Room Overview
This room introduces Structured Query Language (SQL) and how databases store, retrieve, and manage data used by web applications.

---

## Key Concepts Learned

- What SQL is and how databases work
- Tables, rows, and columns
- Basic SQL queries (SELECT, INSERT, UPDATE)
- How web applications interact with databases

---

## Practical Skills Gained

- Understood basic database structure
- Executed simple SQL queries
- Learned how data is stored and retrieved
- Built foundational knowledge for SQL-based attacks

---

## SOC Relevance

SQL fundamentals help SOC analysts to:
- Understand SQL injection attack concepts
- Analyze database-related incidents
- Support investigation of web application breaches
