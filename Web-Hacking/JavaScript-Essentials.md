# JavaScript Essentials

## Room Overview
This room introduces JavaScript and its role in web applications, focusing on how JavaScript runs in the browser and interacts with web pages.

---

## Key Concepts Learned

- What JavaScript is and why it is used
- Client-side scripting in web browsers
- Basic JavaScript syntax and logic
- Interaction with HTML and web pages

---

## Practical Skills Gained

- Understood how JavaScript executes in the browser
- Identified how scripts manipulate web content
- Learned the basics of variables, functions, and logic flow
- Recognized how JavaScript can affect web security

---

## SOC Relevance

JavaScript knowledge helps SOC analysts to:
- Understand client-side web attacks (XSS, malicious scripts)
- Analyze suspicious web behavior
- Investigate browser-based threats
