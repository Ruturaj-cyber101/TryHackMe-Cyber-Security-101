# Nmap: The Basics

## Room Overview
This room introduces Nmap, a widely used network scanning tool for discovering hosts, services, and open ports on a network.

---

## Key Concepts Learned

- What Nmap is and why it is used
- Basic Nmap scan types
- Scanning hosts and networks
- Identifying open ports and services
- Understanding Nmap scan results

---

## Practical Skills Gained

- Performed basic network scans using Nmap
- Identified active hosts on a network
- Discovered open ports and running services
- Interpreted scan output for reconnaissance
- Used Nmap safely for enumeration tasks

---

## SOC Relevance

Nmap helps SOC analysts to:
- Understand attacker reconnaissance techniques
- Identify exposed services and ports
- Support vulnerability assessment and incident investigation
