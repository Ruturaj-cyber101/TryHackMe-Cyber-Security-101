# Defensive Security Intro

## Room Overview
This room provides an introduction to defensive security and the role of blue teams in protecting systems, networks, and data from cyber threats.

---

## Key Concepts Learned

- What defensive security is
- Role of blue teams
- Difference between offensive and defensive security
- Importance of monitoring and detection

---

## Practical Skills Gained

- Understanding of SOC operations
- Awareness of common defensive tools
- Knowledge of incident detection and response
- Foundation for blue team learning

---

## SOC Relevance

This room is highly relevant for SOC analysts as it:
- Explains how security teams defend systems
- Introduces monitoring and alerting concepts
- Builds a defensive mindset for threat detection
