# Public Key Cryptography Basics

## Room Overview
This room introduces public key cryptography and explains how asymmetric encryption is used to securely exchange data.

---

## Key Concepts Learned

- Difference between symmetric and asymmetric encryption
- Public keys vs private keys
- How key pairs are used for secure communication
- Real-world use of public key cryptography (SSL/TLS)

---

## Practical Skills Gained

- Understood how public key encryption works
- Learned how secure key exchange is achieved
- Identified where asymmetric cryptography is used in networks

---

## SOC Relevance

Public key cryptography knowledge helps SOC analysts to:
- Understand HTTPS and secure communications
- Analyze certificate-related security issues
- Support investigations involving encrypted traffic
