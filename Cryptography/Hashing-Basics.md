# Hashing Basics

## Room Overview
This room explains hashing and how it is used to ensure data integrity and securely store passwords.

---

## Key Concepts Learned

- What hashing is and how it works
- Difference between hashing and encryption
- Common hashing algorithms (MD5, SHA family)
- Why hashing is used for password storage

---

## Practical Skills Gained

- Understood one-way hashing functions
- Learned how hashes verify data integrity
- Identified secure vs insecure hashing practices

---

## SOC Relevance

Hashing knowledge helps SOC analysts to:
- Understand password storage mechanisms
- Identify weak or broken hashing algorithms
- Support investigations involving credential compromise
