# John the Ripper: The Basics

## Room Overview
This room introduces John the Ripper, a popular password cracking tool used to test the strength of passwords and hashes.

---

## Key Concepts Learned

- What John the Ripper is and why it is used
- Understanding password hashes
- Basic John the Ripper usage
- Wordlist-based password cracking
- Importance of strong password policies

---

## Practical Skills Gained

- Used John the Ripper to crack password hashes
- Worked with different hash formats
- Applied wordlists for password cracking
- Understood how weak passwords are exploited

---

## SOC Relevance

John the Ripper helps SOC analysts to:
- Understand attacker techniques for password attacks
- Identify weak credentials during investigations
- Recommend stronger password and hashing practices
