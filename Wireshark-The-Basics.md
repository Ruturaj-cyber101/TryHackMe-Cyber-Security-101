# Wireshark: The Basics

## Room Overview
This room introduces Wireshark, a widely used network traffic analysis tool.
It focuses on capturing, inspecting, and understanding packet-level network data.

---

## Key Concepts Learned

- What Wireshark is and why it is used in network analysis
- Understanding packet structure and protocol layers
- Inspecting packet details and headers
- Using basic display filters to analyze traffic
- Navigating packet capture files efficiently

---

## Practical Skills Gained

- Captured and analyzed live network traffic
- Identified protocols within packets
- Examined source and destination IP addresses
- Used filtering to isolate relevant packets
- Developed foundational skills useful for SOC investigations

---

## SOC Relevance

Wireshark is commonly used by SOC analysts to:
- Investigate suspicious network activity
- Analyze malicious traffic patterns
- Support incident response and network troubleshooting
